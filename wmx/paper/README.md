# 天气感知航迹规划论文

## Chen 等（2026）｜RainNet 与两阶段遗传算法

发表于 *Aerospace*。研究民航飞机如何根据短临雷暴预报动态改道。RainNet 从雷达回波预测雷暴演变，规划器将预测转成随时间变化的避让区。第一阶段用改进遗传算法找可行绕行，第二阶段尝试跳过多余航点，按更新后的到达时间复查雷暴交会，以减少转折。

[阅读 PDF](./2026-Aerospace-RainNet%20and%20Two-Stage%20GA%20for%20Thunderstorm%20Rerouting.pdf) · [期刊原文](https://doi.org/10.3390/aerospace13060545)

## Pang 等（2025）｜分散式 IDDPG

发表于 *Advanced Engineering Informatics*。研究多架飞机如何在绕避移动雷暴时保持机间安全间隔。作者用独立深度确定性策略梯度（IDDPG）离线训练共享策略。运行时，每架飞机根据自身状态、邻机和周围天气独立调整下一步航向。

[阅读 PDF](./2025-Adv.%20Eng.%20Inform.-Decentralized%20IDDPG%20for%20Multi-Aircraft%20Thunderstorm%20Avoidance.pdf) · [期刊原文](https://doi.org/10.1016/j.aei.2025.103157)
