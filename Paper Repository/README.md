## 📌 How to Contribute

### 1. 添加论文

每位团队成员都可以分享有价值的学术论文。

- 上传允许共享的论文 PDF 文件。
- 提供论文 DOI、arXiv 或官方出版页面链接。
- 对于无法确认再分发权限的论文，优先分享原文链接。

### 2. 文件命名规范

所有上传的论文统一采用以下命名格式：

**`年份-期刊简写_论文简称_分享者.pdf`**

英文表示：

`Year-JournalAbbreviation_ShortTitle_Contributor.pdf`

例如：

- `2025-TRO_UAVRouting_lzy.pdf`
- `2024-TRC_DroneDelivery_ry.pdf`
- `2026-EJOR_RouteOptimization_wh.pdf`

其中：

- **Year**：论文发表年份。
- **JournalAbbreviation**：期刊或会议名称的常用缩写，例如 TRO、TRC、EJOR。
- **ShortTitle**：能够体现论文主题的简短名称，建议使用英文。
- **Contributor**：论文分享者的姓名缩写，例如 `lzy`、`ry`、`wh`。

如果同一篇论文由多位成员共同推荐，可以在文件名中包含多个成员缩写，例如：

`2025-TRO_UAVRouting_lzy_ry.pdf`

### 3. 更新论文索引

每次新增论文后，请同步更新 README 中的 **Paper List**，记录以下信息：

| Field | Description |
|---|---|
| Title | 论文完整标题 |
| Year | 发表年份 |
| Journal / Conference | 发表期刊或会议 |
| Contributor | 论文分享者 |
| Link | 论文 PDF 文件或原文链接 |

**Contributor 表示发现或分享该论文的团队成员，不代表论文作者。**

### 4. 推荐理由（可选）

鼓励分享者简要介绍：

- 论文研究的问题和背景。
- 采用的核心方法或算法。
- 主要创新点。
- 值得借鉴的研究思路。

## 🤝 Guidelines

1. 欢迎所有成员积极分享有价值的学术论文。
2. 上传论文时，必须按照统一格式命名，并注明分享者的姓名缩写。
3. 新增论文后，请同步更新 Paper List。
4. 尽量避免重复上传相同论文；多人推荐时可以共同署名。
5. 优先分享与团队研究方向相关的高质量文献。
6. 尊重论文版权，优先分享开放获取版本或官方链接。
7. 鼓励团队成员交流论文阅读心得与研究启发。
